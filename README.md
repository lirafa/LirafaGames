# LirafaGames

Site de uma loja de games feito com HTML, CSS e Bootstrap.

## Páginas

- **Início** – carrossel de destaques, informações sobre video games e sobre o PS4 e PS5
- **PS4** – 5 jogos de PlayStation 4 com imagem, descrição e preço
- **PS5** – 5 jogos de PlayStation 5 com imagem, descrição e preço
- **Sobre** – informações da desenvolvedora

## Tecnologias

- HTML5
- CSS3
- Bootstrap 5
